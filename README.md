# AI Chatbot

A plug-and-play AI chatbot widget for website integration. Connects to the **Claude API** or **OpenAI API**, supports custom system prompts, and is styled to drop into any site design.

## Planned Features
- [ ] Floating chat widget (toggle open/close)
- [ ] Claude API + OpenAI API support (switchable)
- [ ] Custom system prompt configuration
- [ ] Conversation history (session-based)
- [ ] Typing indicator
- [ ] Mobile-responsive design
- [ ] Easy embed: one `<script>` tag
- [ ] Rate limiting & input sanitisation

## Tech Stack
- Vanilla JavaScript (no framework dependency)
- CSS (themeable via CSS variables)
- Claude API / OpenAI API

## Usage (planned)
```html
<!-- Drop into any HTML page -->
<script src="chatbot.js" data-api="claude" data-prompt="You are a helpful assistant."></script>
```
